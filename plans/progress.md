## Suggested order

1. Entry page with Word tab and back-stack navigation (§1, §3, §4), so results can be opened.
2. Romaji input and deinflection (§2), with the conjugation engine (§6) and Forms tab.
3. Pitch accent rendering (§7) on result rows and the Word tab.
4. Japanese grammar-label table, then Send to AnkiDroid (§8) and the long-press menu.
5. Kanji half of the database, then the Kanji tab, component tree and practice canvas (§5).

## Open questions

- **Fuzzy ranking:** the spec ranks every fuzzy match below every prefix match, so typing ゆき for 勇気 lists dozens of ゆき… words first. Should a fuzzy match on the whole word (ゆき = ゆうき) rank above prefix matches?

## Known issues

- **Play Protect:** Google Play Protect's on-device scan classified the debug APK as "HARMFUL". This is typical for sideloaded unsigned apps. The app still runs.
- **Speed not measured:** search times on the device (especially one-character prefix searches) and the first-launch copy time haven't been measured. Search timings are now written to the log (`adb logcat -s Search:I`).
